# Hi, I'm Damian, welcome to StuckAtPrototype 👋

I design and ship **open-source consumer hardware** out of Texas. No app. No cloud. Schematics, firmware, and design files all live right here on GitHub.

If you've ever opened a "smart" gadget and found a black box phoning home to a server you'll never see, yeah, me too. That's why everything I build is open by default.

### 🛒 Buy the hardware
**[stuckatprototype.com →](https://stuckatprototype.com)**

- **AirCube**, USB desk air quality sensor (VOC, temp, humidity, AQI, eCO2). Zigbee 3.0, works natively with Home Assistant, color changing VOC indicator. [Repo](https://github.com/StuckAtPrototype/AirCube)
- **Micro Racer**, tiny open source RC car you can actually drive. Built on the Racer platform.
- **The Clock**, premium e-ink desk clock. Offline, no app, ~2 month battery life. *(Launching soon, 200 founder edition units.)*

Ships from Texas. Open sourced after release.
